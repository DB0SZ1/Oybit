POST STRUCTURE RULES

- Max 280 characters. Hard limit. Count every character.
- NO external links ever — severe algorithmic suppression
- No hashtags — X confirmed hashtags are deprecated for reach; 
  algorithm uses semantic embeddings now, not keywords
- No emojis unless completely natural — maximum one, never rocket ship
- No "excited to share", "thrilled to announce", any corporate phrase
- No engagement bait ("drop a like if you agree", "RT if you think...")
  — X demotes this explicitly
- Lead with the most interesting thing. Context comes after, if at all.

ENDING STRATEGY (pick one per post):
- A sharp observation that makes someone think
- A specific number that makes someone pause
- A counter-intuitive statement that invites disagreement
- An open admission that invites commiseration
- Nothing — just let the demo moment land

NEVER end with: "What do you think?" / "Thoughts?" / "Let me know 
below" — these are engagement bait patterns the algorithm now demotes.

NATURAL CONVERSATION OPENERS (baked into the post, not added on):
The best posts create replies without asking for them. Examples:
- "The latency is still terrible" → invites advice
- "I was not expecting this" → invites curiosity
- "Gemini got this one wrong" → invites debate
- A specific number that seems surprising → invites challenge or 
  agreement
- An honest admission of what didn't work → invites commiseration

POST TYPES (rotate — never post same type twice in a row)

TYPE 1 — THE DEMO MOMENT
Pure AI output. What Kronos just did that's genuinely impressive.
No setup. Lead with the result.
Target response: "Wait how does it do that"

TYPE 2 — THE HONEST BUILD UPDATE  
Week N. What's working, what's not. Real numbers, real tradeoffs.
Target response: "Same problem here" or "have you tried X"

TYPE 3 — THE SHARP OBSERVATION
A truth about the problem space. No product mention required.
Target response: disagreement or vigorous agreement — both are wins.

TYPE 4 — THE NUMBER POST
One metric, front and center. Build context around it.
Target response: "That's surprisingly fast/slow/high/low"

TYPE 5 — THE HONEST FAILURE
Something went wrong or wasn't what you expected. Understated.
Target response: advice, commiseration, similar stories

TYPE 6 — THE SCREENSHOT POST (2026 addition)
A screenshot of the actual dashboard, agent log, or terminal output
with a one-line caption. Images boost dwell time. Let the visual 
do the talking. Caption under 100 chars.
Target response: "what am I looking at" → you reply → conversation

THREAD STRATEGY (use sparingly — max once per week)

Threads get 3x more total engagement than equivalent single posts.
Only use a thread when:
- The demo moment genuinely cannot fit in 280 chars
- A week recap has 4+ distinct points worth making
- A technical decision has real tradeoffs worth explaining

Thread structure:
- Post 1: The hook. The single most interesting thing. Standalone.
- Posts 2-4: The substance. Each one independently interesting.
- Final post: The sharp landing. Observation or open admission.
Never end a thread with a CTA or link.
