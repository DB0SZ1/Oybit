## MEME MODULE — GLOBAL RULES

### Concept
A curated dev/founder humor pipeline that seeds early algorithmic reach through DM shares and forwards. Inspired by devhumor.ai. Consistent branding overlay turns curated content into owned content identity over time.

### Source System
- **Input:** 4–5 seed video links provided by Idris (internet-sourced dev/tech humor clips)
- **Tags:** Each video tagged with relevant humor themes (e.g. #debugging, #deploymentfear, #clientrequests, #standupmeeting)
- **Rotation:** System rotates clips based on tag match with content context and schedule
- **Output:** Video file with baked-in caption overlay text + watermark

### Overlay Spec
- Caption text position: Defined per clip (top / middle / bottom)
- Watermark: Account-specific
  - Personal IG/FB: Idris's handle (@idris_ahmad_rufai)
  - LinkedIn personal: Idris's handle + "C0DE"
  - Brand pages (IG + FB): C0DE logo
- Font: Clean, readable, high contrast — legible on all backgrounds
- No competitor watermarks (TikTok, CapCut, etc.) — native output only

### Tone by Platform
| Platform | Meme Tone | Example Theme |
|---|---|---|
| Personal IG | Relatable dev humor; peer-level | "it works on my machine," git merge conflicts, 2 AM debugging |
| Personal FB | Slightly broader; business owners get it too | "client said just one small change," NEPA + server uptime |
| LinkedIn Personal | Professional; CTO/founder audience | MVP scope creep, pitch deck vs reality, sprint planning lies |
| Brand IG | Agency-client humor; founder-appropriate | "client wants Apple website for ₦50k," revision request #12 |
| Brand FB Page | Business owner relatable; approachable | "my nephew will build the website," WhatsApp orders vs proper site |

### Posting Rules
- **Never two meme posts back-to-back** on any platform
- **Brand pages rule:** If the meme would make a potential enterprise client question credibility, cut it
- **LinkedIn rule:** Would a VC seeing this unfollow? If yes, cut it
- Caption on meme posts is short (1–3 lines max). Let the video land. Always end with a soft CTA.

## SECTION 3: ALGORITHM RULES — VERIFIED 2026

### Instagram Algorithm
**Ranking Signals:**
1. DM Shares (strongest signal — memes drive this)
2. Watch Time / Completion Rate
3. Saves (carousels earn these)
4. Comments
5. Likes (weakest signal)

**Critical Rules:**
- Reels must include audio to surface in Reels feed
- No TikTok/CapCut watermarks — suppressed from Explore
- First 3 seconds = hook. If the viewer doesn't understand why to stay, they're gone.
- Keywords in captions now outperform hashtags for discovery (SEO > hashtags)
- 15 hashtags max in first comment

### Facebook Algorithm
**Key Rules:**
- Up to 50% of feed is now recommended content from accounts you don't follow
- Reels get **135% more reach** than photos — meme Reels are the primary organic reach lever
- **Personal profiles get significantly more reach than Pages**
- External links = reach penalty — links go in first comment ONLY
- Reply to comments within 6 hours — signals active discussion, boosts ranking
- Saves and shares > likes

### LinkedIn Algorithm
**Critical Rules:**
- Personal profiles generate **8x more engagement** than company pages
- First **60–90 minutes** after posting = golden window
- External links in post body = **40% less initial reach** — add in first comment after 10+ reactions
- NEVER start a post with "I"
- Native PDF carousels = 3x impressions vs static images
- Substantive comments (3+ sentences) outperform short ones significantly
- Seed every post: DM 3–5 connections immediately after publishing
